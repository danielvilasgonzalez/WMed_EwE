# Example regions for a custom WMed-EwEbuilder run

## cetacean_migration_corridor_RD699_2018

The Mediterranean cetacean migration corridor (*Corredor de migración de cetáceos del Mediterráneo*), a Spanish Marine Protected Area between the Catalan and Valencian coast and the Balearic Islands.

- **Source of the boundary:** Real Decreto 699/2018, de 29 de junio (BOE-A-2018-9034), article 1.3: the 16 vertices of the protected area (ETRS89 geographic coordinates), joined in order and closed from vertex 16 back to vertex 1. Built from the legal text, so it can be shared with the code.
- **Check:** area in ETRS89 / UTM 31N = 46,385.7 km², the same as the area stated in article 1.2 (46.385,70 km²).
- **Files:** `.shp/.shx/.dbf/.prj` (WGS84) and `.geojson`.
- The same area is in the WDPA as site 555596226 (Protected Planet). The WDPA polygon itself is not included here: its terms do not allow redistribution.
